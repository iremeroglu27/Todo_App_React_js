# To-Do List

React ile geliştirilmiş, görev ekleme ve takip etmeyi kolaylaştıran basit bir yapılacaklar listesi uygulaması.

## Özellikler

- Yeni görev ekleme
- Enter tuşuyla hızlı görev ekleme
- Görevleri tamamlandı olarak işaretleme
- Tamamlanan görevleri üstü çizili biçimde görüntüleme
- Görev silme
- Görevleri tarayıcı `localStorage` alanında saklama; sayfa yenilense bile liste korunur
- Responsive arayüz

## Kullanılan Teknolojiler

- React
- Vite
- Tailwind CSS
- JavaScript
- HTML / CSS

## Kurulum

Projeyi bilgisayarınıza indirdikten sonra terminalde proje klasörüne gidin ve bağımlılıkları yükleyin:

```bash
npm install
```

Geliştirme sunucusunu başlatın:

```bash
npm run dev
```

Uygulama, terminalde gösterilen yerel bağlantı üzerinden görüntülenebilir.

## Kullanım

1. Giriş alanına yapmak istediğiniz görevi yazın.
2. **Add** düğmesine tıklayın veya Enter tuşuna basın.
3. Görevi tamamlamak için görev satırındaki işaretleme simgesine tıklayın.
4. Bir görevi kaldırmak için çöp kutusu simgesini kullanın.

## Proje Komutları

```bash
npm run dev      # Geliştirme sunucusunu başlatır
npm run build    # Üretim için proje çıktısı oluşturur
npm run preview  # Üretim çıktısını yerelde önizler
npm run lint     # Kod kalitesi kontrollerini çalıştırır
```
